EVMCalc: earned value metrics without opening the full PPM suite

2026-07-22 · project controls · open source

Earned value management is standard language in project controls: BAC, PV, EV, AC become CV, SV, CPI, SPI, EAC, ETC, VAC, TCPI. Spreadsheets reimplement the formulas every status cycle. Enterprise tools bury them three menus deep. Controllers still need a clear, private place to run the numbers.

EVMCalc is live sybilgambleyyu.github.io/EVMCalc · Source

Enter budget and status values; get variances, indices, and forecasts (CPI, remaining-at-budget, and CPI×SPI composite EAC). Keep multiple projects and status snapshots. Export a report or history CSV. Data stays in the browser.

Not a scheduling tool and not a substitute for formal contract EVM systems — a fast, local worksheet for the math that drives status reports.
